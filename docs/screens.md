# 화면 구성 (design-reference/app-mockup.jsx 기준)

각 화면은 목업 파일의 컴포넌트명과 1:1 대응됨. 실제 개발 시 컴포넌트명을 참고해서 화면/파일을 나누면 편함.

## 온보딩 (`Onboarding`) — 5단계
1. **프로필 설정**: 닉네임 + 아바타 컬러 선택 (앱 첫 실행 시 가장 먼저 등장)
2. **스포츠 선택**: 러닝/헬스/기타
3. **시작 방법 선택**: 그룹 만들기 vs 초대코드 참여
4. **분기**: (만들기) 그룹 이름 입력 / (참여) 6자리 코드 입력
5. **완료**: 시나리오별 다른 메시지 노출

진행률 바(5칸) + 뒤로가기 버튼 상단 고정. 콘텐츠와 하단 버튼 사이 고정 여백(mt-8) 유지 — 작은 화면에서 버튼이 붙어 보이는 문제 있었음, 해결됨.

## 피드 (`Feed`)
그룹원의 오늘 인증을 비브 카드 형태로 표시. 상단 크루명 클릭 시 그룹 관리 화면으로 이동. 우측 상단 스트릭 배지 상시 노출.

## 업로드 (`UploadModal`)
그룹이 2개 이상이면 상단에 "어느 그룹에 인증할지" 선택 칩 노출(기본값 = 현재 활성 그룹). 종목 선택 탭(러닝/헬스/기타) → 종목별 통계 카드(러닝: 지도+거리/페이스/시간, 헬스: 부위/무게/세트, 기타: 활동/시간) → 인증하기 → 스탬프 pop 애니메이션 → 완료 화면(어느 그룹에 인증했는지 표시).

## 챌린지 (`Challenge`, `ChallengeDetailOverlay`, `TemplatePickerOverlay`)
- 목록: 종목 태그 + 참여중 표시 + 하단에 "커스텀 챌린지 만들기"(유료 잠금) CTA
- 상세: 진행률(그룹 합산형/개인형 자동 구분), 참여자 순위, 규칙, 참여/탈퇴 토글
- 템플릿 고르기(+ 버튼): 고정 규칙 템플릿 중 선택 → 미리보기 → 우리 그룹에 즉시 시작 (무료 기능)

## 랭킹 (`Ranking`)
그룹 내 랭킹(무료) + 전체 랭킹(블러 처리 + 잠금 CTA, 구독 화면으로 연결)

## 마이페이지 (`MyPage`)
스트릭 대형 숫자, 배지 컬렉션, 그룹 관리 진입, 구독 유도 카드, 설정 진입(톱니바퀴 아이콘)

## 그룹 관리 (`GroupsOverlay`)
목록(내 그룹들 — 이제 다중 그룹 지원): 카드를 탭하면 해당 그룹 피드로 즉시 전환 후 오버레이 닫힘, 우측 톱니바퀴 아이콘을 누르면 초대코드·멤버 관리 상세 화면으로 이동. 현재 보고 있는 그룹엔 "사용중" 태그 표시. 상세 화면: 초대코드+복사, 멤버 리스트, 크루장 표시, 그룹 나가기/삭제.

## 설정 (`SettingsOverlay`)
프로필 요약(편집 진입) / 알림 토글 3종 / 구독 관리·로그아웃 / 회원탈퇴 / 프로필 편집 서브뷰(닉네임+아바타 재설정)

## 구독 (`SubscribeOverlay`)
월간/연간 플랜 토글, 구독 시 열리는 기능 6종 체크리스트, 결제 버튼 → 완료 화면. 3곳(마이페이지/랭킹/그룹 추가)에서 진입 가능.
