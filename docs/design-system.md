# 디자인 시스템

## 컨셉
"오늘의 인증 도장" — 러닝 비브(경주 배번호표) + 우표 스탬프 모티프.
필터 대신 정직한 스탬프 하나로 인증한다는 "진정성" 원칙을 시각적으로 구현.

## 컬러 팔레트

| 이름 | 용도 | HEX |
|---|---|---|
| Concrete | 배경(밝은 콘크리트 회백색) | `#EDEBE6` |
| Concrete Dark | 구분선/보더 | `#E1DED7` |
| Asphalt | 본문 텍스트 / 다크 컴포넌트 배경 | `#1F2023` |
| Hi-Vis Lime | 포인트(CTA, 스트릭, 인증 성공) | `#D7FF3F` |
| Track Red | 강조(랭킹, 마감임박, 우표 테두리) | `#E63B2E` |
| Slate | 보조 텍스트 | `#6E7075` |
| White | 카드 배경 | `#FAFAF8` |

다크모드 기본이 아닌 **밝은 콘크리트 배경**을 기본으로 한 이유: 흔한 "다크+네온" AI 생성 톤을 피하면서 아스팔트/트랙 질감을 살리기 위함.

## 타이포그래피
- **디스플레이**: Bebas Neue (컨덴스드 스포츠체) — 스트릭 숫자, 헤드라인 전용, 남용 금지
- **본문**: Manrope (400/500/700/800) — 휴머니스트 산세리프, 가독성 우선
- **데이터/시간**: JetBrains Mono (500/700) — 거리·페이스·타임스탬프·초대코드 전용

## 시그니처 UI 컴포넌트
- **PostageStamp**: 이중 붉은 테두리(간격 있는 double border) + JetBrains Mono. 인증 시각/기록을 표시하는 모든 곳에 재사용. 처음엔 우표 톱니(perforation) 테두리로 시도했으나 작은 사이즈에서 지저분해 보여 심플한 이중선으로 확정.
- **BibCard**: 그룹 피드의 각 인증 카드. 좌우에 원형 노치("bib-notch")로 러닝 배번호표 느낌. 미인증 시 점선 테두리로 "은은한 압박" 표현.
- **RouteMap**: 러닝 인증 시 노출되는 SVG 기반 스타일라이즈드 경로 그래픽(실제 지도 아님, 톤 유지용). **실제 구현 시 react-native-maps(Apple MapKit/Google Maps)로 교체.**
- **Toggle**: 라임/콘크리트 톤의 커스텀 토글 스위치 (알림 설정 등에 사용)

## 종목별 스탬프 텍스트 포맷
- 러닝: `시간 · 거리 · 페이스` (예: `07:12 · 5.2km · 5'42"`)
- 헬스: `시간 · 부위 무게×세트` (예: `19:44 · 가슴 60kg×5set`)
- 기타: `시간 · 활동 시간` (예: `20:10 · 요가 45분`)

## 모션
- 인증 완료 시 스탬프가 "쿵" 찍히는 느낌의 pop 애니메이션 (`stamp-pop`, cubic-bezier 오버슈트 → 최종 -7deg 회전)
