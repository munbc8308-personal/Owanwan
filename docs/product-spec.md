# 제품 기획

## 컨셉
"매일, 있는 그대로" — 친구와 함께 매일 한 번, 꾸민 것 없이 운동을 인증하는 소셜 앱.
타겟: 국내 MZ세대, 친구 그룹 단위 사용. 참고 트렌드: setlog류 "강제적 동시성" 소셜 앱, NRC식 챌린지 게임화, 챌린저스식 보상 동기부여.

## 핵심 루프
인증(사진/영상) → 그룹 피드 자동 취합 → 스트릭 증가 → 그룹 내 랭킹 → 챌린지 참여 → (자연스러운 지점에서) 구독 전환

## 수익 모델
- 구독(프리미엄) 단일 모델. 광고 없음. 예치금/보상형·B2B는 시즌2 이후 검토.
- 가격: **월 1,500원 / 연 15,000원**(월 환산 1,250원). 프리트라이얼 없음 — 결제 허들을 최대한 낮춰 이탈(해지) 트리거를 줄이는 전략.
- 결제는 앱스토어/구글플레이 인앱결제(IAP) 필수, RevenueCat으로 통합 관리 예정.

## 무료 / 유료 기능 경계

| 기능 | 무료 | 유료 |
|---|---|---|
| 인증 업로드(사진) | 1일 1회, 720p 자동 압축 | 1일 3~5회, 원본 화질(1080p) |
| 인증 업로드(영상) | 불가 | 가능 (최대 1분) |
| 보관 기간 | 30일 후 자동 삭제 | 무기한 보관 |
| 그룹 인원 | 5명 | 확장(무제한 또는 30명) |
| 그룹 개수 | 1개 | 추가 가능(구독 유도) |
| 그룹 내 기본 랭킹 | 무료 | — |
| 전체/세그먼트 랭킹 | 잠금 | 가능 |
| 템플릿 챌린지 참여 | 가능(고정 규칙) | 가능 |
| 커스텀 챌린지 생성 | 불가 | 가능 |
| 데이터 내보내기(CSV) | 불가 | 가능 |
| 웨어러블 연동 | 불가 | 가능 |
| 광고 | 없음 | 없음 |

**판단 기준**: "이 기능이 없으면 친구랑 같이 못 논다" → 무료 / "없어도 재밌지만 진지해지면 필요하다" → 유료.

## MVP 우선순위
1. **필수**: 인증 업로드, 홈 피드, 그룹 생성/참여, 그룹 내 랭킹, 기본 배지·스트릭, 온보딩(프로필+그룹)
2. **출시 직후**: 템플릿 챌린지, 구독 결제(영상+원본화질 해제)
3. **트래픽 보고 판단**: 전체 랭킹, 커스텀 챌린지, 웨어러블 연동

## 유저 스토리보드 (핵심 여정)
1. 설치 & 친구 초대로 첫 진입 (진입장벽 최소화)
2. 온보딩 마지막에 첫 인증 유도 → 스탬프 임팩트 모션 → 첫 배지
3. 그룹 피드에서 친구 인증 확인 (미인증 슬롯 = 은은한 압박)
4. 스트릭 형성 (며칠간 반복 인증)
5. **위기**: 스트릭 끊길 뻔하다 겨우 인증 성공 → 핵심 리텐션 지점
6. 챌린지 발견 및 참여
7. **유료 전환 트리거 3곳**: 영상 기록 시도 / 전체 랭킹 확인 시도 / 6번째 친구 초대 시도
8. 구독 후 헤비유저로 정착

## 종목(운동 종류)별 분화
- **러닝**: 거리/페이스/시간 + GPS 경로. 챌린지 예: "이번 주 30km 채우기"(그룹 합산형)
- **헬스**: 부위/무게/세트. 챌린지 예: "이번 주 스쿼트 500개"(그룹 합산형)
- **기타**: 활동명/시간. 챌린지 예: "미라클모닝 5일 연속"(개인 스트릭형), "주 3회 인증"(개인형)

챌린지는 `groupGoal`(그룹 합산 여부)과 `sport`(종목 태그) 필드로 구분해서 설계할 것.
